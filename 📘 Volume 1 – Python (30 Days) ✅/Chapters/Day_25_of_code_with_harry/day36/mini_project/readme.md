# 🧮 Safe Calculator (Python)

## 📌 Project

A simple calculator built using Python.

This project performs basic arithmetic operations while handling user errors using Python's Exception Handling (`try` and `except`).

---

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Prevents ValueError
- Prevents ZeroDivisionError
- Menu Driven Program
- Infinite Loop until Exit

---

## Concepts Used

- Variables
- Input
- if-elif-else
- while loop
- try
- except
- Exception Handling
- ZeroDivisionError
- ValueError

---

## Menu

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit
