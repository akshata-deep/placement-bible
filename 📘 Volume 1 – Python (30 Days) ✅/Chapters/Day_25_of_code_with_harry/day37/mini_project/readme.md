# 📊 Student Result Viewer (Python)

A simple Python mini project that demonstrates **Exception Handling (`try`, `except`, `finally`)**.

## 📚 Concepts Used

- try
- except
- finally
- int()
- input()
- print()

## 🚀 Features

- Takes student marks as input.
- Handles invalid input safely.
- Prevents the program from crashing.
- Always displays a thank-you message using `finally`.

## ▶️ Example

### Valid Input

```
Enter the student marks:
85

Percentage: 85%

Thank you for using Student Result Viewer.
```

### Invalid Input

```
Enter the student marks:
abc

Error

Thank you for using Student Result Viewer.
```
