# 📌 Shopping Cart Management System

## 📖 Description

A menu-driven Python application that simulates a simple shopping cart management system. Users can view products, search for products, add new products, and remove existing products using Python lists and functions.

---

## 🚀 Features

- View available products
- Search for a product
- Add a new product
- Prevent duplicate products
- Remove existing products
- Menu-driven interface
- Exit option

---

## 🛠️ Concepts Used

- Functions
- Lists
- List Methods
  - append()
  - remove()
- Membership Operators (`in`)
- while Loop
- Conditional Statements
- User Input
