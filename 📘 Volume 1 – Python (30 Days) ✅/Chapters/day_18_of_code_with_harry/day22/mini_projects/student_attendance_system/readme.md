# 📌 Student Attendance System

## 📖 Description
A simple Python program that manages student attendance using lists. It displays all students with serial numbers and checks whether a student's name exists in the attendance list.

---

## 🚀 Features

- Store student names using a Python list
- Display all students with serial numbers
- Search for a student by name
- Check attendance using the `in` operator
- Beginner-friendly implementation

---

## 🛠️ Concepts Used

- Lists
- List Traversal
- for Loop
- Variables
- Input/Output
- Membership Operators (`in`)
- Conditional Statements (`if-else`)
