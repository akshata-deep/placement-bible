# ✈️ Airport Flight System

## 📌 Overview

A Python console application that manages flight numbers using **Tuples**.

The project demonstrates searching, slicing, indexing, and displaying tuple data in a menu-driven system.

---

## 🚀 Features

- View Flight Numbers
- Search Flight Number
- Show Total Flights
- Display First Five Flights
- Exit the Program

---

## 🛠 Technologies Used

- Python 3

---

## 📚 Python Concepts Used

- Tuple
- Tuple Indexing
- Tuple Slicing
- Membership Operator (`in`)
- `len()`
- Functions
- Menu Driven Programming
- Conditional Statements
- Loops

---

## 🎯 Learning Outcome

After completing this project, you will understand:

- Why tuples are immutable
- How tuple slicing works
- How to search data inside tuples
- How to display tuple elements
- How to build real-world tuple-based applications

---

```bash
python airport_flight_system.py
```
