# 👨‍💼 Employee ID Verification System

## 📌 Overview

A simple Python console application that stores employee IDs using **Tuples** and allows users to verify employee records.

This project demonstrates how tuples can safely store fixed data that should not be modified.

---

## 🚀 Features

- View all Employee IDs
- Search Employee ID
- Display Total Number of Employees
- Exit the program

---

## 🛠 Technologies Used

- Python 3

---

## 📚 Python Concepts Used

- Tuple
- Tuple Indexing
- Membership Operator (`in`)
- `index()`
- `len()`
- Functions
- Menu Driven Programming
- Conditional Statements
- Loops

---

## 🎯 Learning Outcome

After completing this project, you will understand:

- How tuples store fixed data
- How to search values inside a tuple
- How to find the index of an element
- How to count the total elements in a tuple
- How to build menu-driven applications using tuples
