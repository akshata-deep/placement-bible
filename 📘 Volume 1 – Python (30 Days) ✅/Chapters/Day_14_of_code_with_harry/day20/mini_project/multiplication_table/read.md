# Multiplication Table Generator

## 📖 Objective

This project prints the multiplication table of any number entered by the user using Python Functions.

## 🛠 Concepts Used

- Functions (`def`)
- Function Calling
- Parameters
- User Input
- for Loop
- Formatted Strings (f-string)

## ▶️ How to Run

1. Run `main.py`
2. Enter any number.
3. The multiplication table from 1 to 10 will be displayed.

## 💻 Sample Output

Enter the number: 7

7 X 1 = 7
7 X 2 = 14
7 X 3 = 21
7 X 4 = 28
7 X 5 = 35
7 X 6 = 42
7 X 7 = 49
7 X 8 = 56
7 X 9 = 63
7 X 10 = 70
