# 🎓 Student Result Management System

## 📌 Project Description

Student Result Management System is a Python-based mini project that calculates and displays a student's academic result.

The program takes student details and subject marks as input, calculates total marks, average marks, grade, and displays the final PASS/FAIL result.

This project is created to practice Python functions and basic programming concepts.

---

## 🚀 Features

- Enter student name and roll number
- Enter marks of multiple subjects
- Calculate total marks
- Calculate average marks
- Generate grade
- Display final result
- Uses functions for better code organization

---

## 🛠️ Technologies Used

- Python 3

---

## 📚 Concepts Used

- Functions
- Function arguments
- Return values
- User input
- Conditional statements
- Arithmetic operations
- String formatting
