# 🎓 Student Marks Manager

A simple Python mini project that uses a **Dictionary** to store and manage student names and their marks.

## 📌 Project Overview

The **Student Marks Manager** is a menu-driven Python program where users can:

- Add a student and their marks
- Search for a student's marks
- Display all student names
- Display all student marks
- Exit the program

The project mainly focuses on practicing **Python Dictionaries and Key-Value Pairs**.

---

## ✨ Features

- ➕ Add Student
- 🔍 Search Student
- 👨‍🎓 Display All Students
- 📊 Display All Marks
- 🚪 Exit Program
