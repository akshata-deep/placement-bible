# 👨‍💼 Employee Performance Manager

A simple Python mini project that uses a **Dictionary** to store and manage employee IDs and their performance scores.

## 📌 Project Overview

The **Employee Performance Manager** is a menu-driven Python program where users can:

- Add a new employee and their performance
- Update an employee's performance
- Remove a specific employee
- Remove the last employee
- Display all employee IDs
- Clear all employee records
- Exit the program

The project mainly focuses on practicing **Python Dictionaries and Dictionary Methods**.
