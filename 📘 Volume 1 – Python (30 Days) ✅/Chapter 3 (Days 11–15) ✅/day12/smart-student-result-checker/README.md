# 🎓 Smart Student Result Checker

## 📌 Project Description

This is a beginner Python project that checks a student's result based on the marks entered by the user.

The program automatically calculates the student's grade and displays whether the student has passed or failed.

---

## 🚀 Features

- Accept Student Name
- Accept USN
- Accept Marks
- Calculate Grade
- Display Pass/Fail
- Print a formatted report

---

## 🛠 Technologies Used

- Python 3
