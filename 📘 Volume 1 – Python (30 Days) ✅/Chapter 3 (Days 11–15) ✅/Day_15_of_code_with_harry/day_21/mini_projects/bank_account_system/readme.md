# 🏦 Bank Account System (Python)

A simple menu-driven **Bank Account System** built using **Python Functions**. This project demonstrates the use of functions, loops, conditions, return statements, and input validation.

---

## 📌 Features

- 💰 Deposit Money
- 💸 Withdraw Money
- 💳 Check Account Balance
- 🔄 Menu-Driven Program
- ✅ Prevents Negative Deposits
- ✅ Prevents Negative Withdrawals
- ✅ Prevents Withdrawing More Than Available Balance
- 🚪 Exit Option

---

## 🛠️ Concepts Used

- Functions (`def`)
- Function Parameters
- Return Statement (`return`)
- `if-elif-else`
- `while` Loop
- User Input
- Input Validation
- Variables
