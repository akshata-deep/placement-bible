# 🏧 ATM Management System (Python)

A menu-driven ATM Management System developed using Python functions. This project simulates basic ATM operations while demonstrating modular programming, input validation, and function-based design.

---

## 📌 Features

- 💳 Check Balance
- 💰 Deposit Money
- 💸 Withdraw Money
- 📄 Mini Statement
- 🔄 Menu-Driven Interface
- ✅ Input Validation
- ✅ Prevents Invalid Transactions
- 🚪 Exit Option

---

## 🛠️ Concepts Used

- Functions
- Parameters
- Return Statements
- While Loop
- Conditional Statements
- Variables
- User Input
- Input Validation
