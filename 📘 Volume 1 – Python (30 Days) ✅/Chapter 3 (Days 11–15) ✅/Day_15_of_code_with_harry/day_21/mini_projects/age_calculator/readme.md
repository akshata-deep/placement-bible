# 🎂 Age Calculator (Python)

A simple Python project that calculates a person's age based on their birth year. The project is built using functions to demonstrate modular programming and clean code organization.

---

## 📌 Features

- 👤 Accepts user's name
- 📅 Accepts birth year
- 🧮 Calculates age
- 📄 Displays a formatted result
- 🧩 Uses separate functions for each task

---

## 🛠️ Concepts Used

- Functions
- Parameters
- Return Statements
- Variables
- User Input
- Arithmetic Operations
- Formatted Output
